Browser engine


      
Camoufox is the stealth engine (patched Firefox, free, no key). If it is not installed, bots can still be added and tokens issued, but browser tools will return a clear "not installed" error until the install finishes. Install downloads the browser build once. On a minimal server it also needs three system libraries (libgtk-3, libx11-xcb, libasound2) - if the install log complains about a missing .so file, install those with apt and retry.

Security

      
Credential vault

      
Native encrypted credentials for each bot. No Vaultwarden, Docker, or separate login required. Add a login here; agents only request autofill by credential ID. Keep the Portal owner's machine and master key secure.
